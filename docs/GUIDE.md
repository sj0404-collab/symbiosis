# Symbiosis: инструкция пользования

Тот же текст есть в приложении: **Руководство** (кнопка на стартовом экране, а также
«Инструменты» → «Руководство пользования»). Если инструкция и приложение когда-нибудь
разойдутся, права инструкция: она проверяется тестом на то, что каждый раздел ссылается
на существующий экран (`tests/NativeLibraryPresenterTest.kt`).

Версия текста: 2.

---

## 1. С чего начать: три шага

Порядок важен. Пока нет ключей, ни один дамп не откроется, и пустой список будет
выглядеть как «папка не та», хотя дело не в ней.

1. **Ключи и прошивка.** «Ключи» → `prod.keys`, затем файлы прошивки. Без них заголовок
   файла зашифрован: приложение видит файл, но не знает, что это за игра, и помечает его
   «нет ключей».
2. **Папка с играми.** «Папки» → «Добавить папку». Выберите папку, где лежат NSP, XCI,
   NCA или сжатые NSZ. Папок может быть несколько, вложенность читается.
3. **Нажать игру.** Вернитесь на стартовый экран: игры уже в списке. Нажатие запускает
   игру, долгое нажатие открывает её свойства — масштаб, драйвер, сейвы.

---

## 2. Экран библиотеки: что означают значки

Стартовый экран — нативная библиотека. Список показывает **все** файлы в выбранных
папках, а не только те, что запускаются. Поэтому «игр нет» больше не значит
«файлы не нашлись».

| Что видно | Что это значит |
|---|---|
| Строка сверху | Счёт по всем папкам без фильтров: `12 игр · 3 обновления · 40 сжатых → Конвертер · 2 не читаются` |
| Метка на плитке | Формат файла: `nsp`, `xci`, `nca`, `nro`. Обновления и DLC стоят рядом со своей игрой отдельными плитками |
| Пометка «сжатый» | Образ упакован (NSZ/XCZ/NCZ). Сначала распаковывается — Конвертером |
| Пометка «нет ключей» | Заголовок не расшифровался: нужны `prod.keys` и прошивка |
| Пометка «часть» | Разрезанный образ: `.nsp.00`, `.nsp.01` … нужны все части |
| Фильтры | «Все файлы» / «Запускается» / «Не запускается» |
| Поиск | Ищет по названию, Title ID и имени файла |
| Долгое нажатие | Свойства конкретной игры: настройки только для неё, сейвы, удаление |

---

## 3. Файл виден, но не запускается

Нажмите такую плитку — приложение скажет причину словами и предложит действие.

| Причина | Что делать |
|---|---|
| Сжатый NSZ / XCZ / NCZ | «Конвертер» → выбрать файл → подождать. Распаковка идёт на телефоне и занимает столько же места, сколько сам образ: освободите его заранее. Готовый NSP появится в папке конвертера и сразу в библиотеке |
| Часть разрезанного образа (`.nsp.00`, `.xci.01`) | Ядро открывает только целый файл. Положите все части в одну папку — библиотека склеит их в одну игру |
| Нет ключей | «Ключи» → `prod.keys`, затем прошивка. После установки нажмите «Искать игры»: заголовки расшифруются. Файлы при этом никуда не переносятся |

## 4. Где что лежит

Главное — на стартовом экране. Остальное открывается кнопками сверху и из «Инструментов».

| Экран | Что там |
|---|---|
| **Библиотека** (стартовый) | Игры, поиск, фильтры, запуск, свойства игры по долгому нажатию |
| **Папки** | Откуда берутся игры: добавить или убрать папку, посмотреть, что внутри |
| **Конвертер** | Распаковка сжатых образов; здесь же очередь и готовые NSP |
| **Ключи** | `prod.keys` и прошивка консоли |
| **Инструменты** | Подбор FPS, диагностика, движки, утилиты ROM, сейвы, лаунчеры, справочник настроек, руководство |
| **Два ядра** | Гибрид: Eden + Kenji-NX, общие и свои настройки, ядро по умолчанию |
| **Руководство** | Эта инструкция, с поиском |
| **Расширенная панель** | Старая универсальная панель: пространства, выбор ядра, тонкие переключатели. Для обычной игры не нужна |

Кнопки стартового экрана, слева направо: **Искать игры**, **Папки**, **Конвертер**,
**Ключи**, **Инструменты**, **Руководство**.

## 5. Папки с играми и конвертер

**Папки.** «Инструменты» → «Папки с играми». Кнопка «Добавить папку» — прямо здесь,
долгое нажатие на папку — «Пересканировать» или «Убрать из списка».

Две вещи, которые раньше работали неправильно и теперь исправлены:

- **Папки больше не пропадают.** Было: папка, к которой отозвали доступ (а система отзывает
  его сама, если приложение упало), удалялась из настроек при первом же обходе — навсегда,
  вместе со списком игр в ней. Стало: папка остаётся в списке и помечается «нет доступа»;
  нажатие на неё открывает выбор папки, чтобы вернуть доступ. Плюс у приложения есть вторая
  копия списка — если настройки после сбоя остались недописанными (а именно так и появляется
  «осталась одна папка из четырёх»), недостающие возвращаются из копии.
- **Вложенные папки не съедают друг друга.** Если добавить `Games` и `Games/Switch`, обе
  остаются в списке; дубликаты игр отсекаются при показе, а не удалением папок.

**Конвертер.** Даёте ему NSZ / XCZ / NCZ — получаете файл, который открывается.

- Работа идёт в **уведомлении в шторке**: видно, какой файл распаковывается и сколько
  осталось, есть кнопка «Остановить». Можно уйти из приложения — распаковка не прервётся.
- Результат кладётся в **`Download/Symbiosis`** — папку видно в проводнике и по кабелю.
  Точный путь написан и в уведомлении, и в приложении. Если доступа к «Загрузкам» нет,
  приложение скажет об этом и положит файл в свою папку, а не сделает вид, что всё хорошо.
- Не забудьте разрешить уведомления, когда приложение попросит: без разрешения на Android 13+
  уведомление не показывается — и прогресс будет «невидимым».

## 6. Если игра вылетает при выходе

Приложение записывает последние шаги: запуск какой игры, остановка эмуляции, возврат
в библиотеку. Откройте «Инструменты» → «Диагностика» — вверху будет «Последние шаги перед
выходом»: время, шаги и пометка, завершилась ли прошлая сессия сбоем. Кнопка «Скопировать
отчёт» копирует это вместе с разбором.

Это нужно, чтобы не гадать: по шагам видно, падает ли ядро при запуске, при разрушении окна
или уже после возврата в библиотеку. Пришлите этот текст — по нему видно, где искать.

## 7. Второе ядро: скачать, проверить, отдать оригиналу

«Инструменты» → «Два ядра» → карточка **Kenji-NX**.

- **«Скачать (55 МБ)»** — качает один файл с релиза, проверяет контрольную сумму, делает
  файл доступным только для чтения и сразу пробует загрузить. Сообщение о ходе и итоге —
  плашкой **сверху экрана**, рядом с кнопкой.
- **«Проверить»** — запускает ядро в отдельном процессе `:kenji`. Так проверка, которая
  падает, роняет только этот процесс, а не приложение: вместо исчезновения будет фраза
  с причиной.
- Под карточкой — **«Проверено на этом устройстве»**: процессор, разрядность процесса,
  версия Android, размер страниц памяти и выравнивание скачанного ядра. Если что-то не
  подходит, там же написано, почему и что делать.

**Если ядро не подходит именно вашему телефону.** Это бывает по трём причинам, и все они
видны в этом блоке: процессор не arm64, приложение установлено 32-битным, или ядро собрано
с выравниванием 4 КБ, а телефон работает со страницами 16 КБ. На релизном ядре выравнивание
16 КБ, поэтому последний случай к нашей сборке не относится.

**Запасной путь, который работает всегда.** Если на телефоне установлен оригинальный APK
Kenji, приложение предложит «Играть через Kenji» — и на плитке игры, поставленной на второе
ядро, тоже: своё ядро не готово → игра открывается в официальном приложении, а не молча
уходит на Eden. Так вы получаете ровно то поведение, к которому привыкли в оригинале.

## 8. Плагины: починить, не пересобирая

Бывает так: игра на втором ядре вылетает, или на драйвере Mali мигает картинка, а новой
сборки ждать долго. Для этого есть плагины — **«Инструменты» → «Плагины»**.

Плагин — это файл с правилами: «если у игры такой-то признак — такая-то настройка, такое-то
ядро или такая-то пометка». **Кода он не исполняет.** Поэтому его можно взять у кого угодно и
не бояться: самое плохое, что он сделает, — выставит неверную настройку, и это видно в списке
и выключается одним нажатием.

Что уже есть:

| Плагин | Что делает | Включён? |
|---|---|---|
| `mali-safe` | На Mali отключает «быстрое время GPU» и анизотропию; предупреждает, если памяти меньше 6 ГБ | да |
| `lowram-eden` | На устройстве меньше 6 ГБ всегда запускает игры на Eden | нет |
| `template` | Не срабатывает никогда — образец, с которого можно начать свой | нет |

Свой плагин: в «Плагинах» нажмите «Скопировать путь», положите туда `.json` по образцу и
нажмите «Перечитать». Файл с тем же `id`, что у встроенного, **заменяет его** — так чинится
встроенное правило, не дожидаясь новой сборки.

Что можно в условии: `title`, `path`, `ext`, `titleId`, `gpu`, `engine`, `ramGb`. Сравнение —
шаблон со звёздочкой (`"*mali*"`) или число (`{"ramGb": {"lt": 6}}`). Несколько полей в одном
условии — «и», массив значений — «любое из».

Что можно сделать: `setting` (настройки ядра — только те, что есть на экране «Два ядра»),
`core` (запускать другое ядро), `file` (пометка на плитке), `banner` (сообщение над списком).

```json
{
  "schema": 1,
  "id": "splatoon-fix",
  "name": "Splatoon 3 на Eden",
  "priority": 200,
  "rules": [
    { "type": "core", "when": { "title": "Splatoon*" }, "core": "eden",
      "reason": "на втором ядре вылетает после заставки" }
  ]
}
```

Ошибка в файле не ломает приложение: плагин не применится, а на экране появится причина —
например «правило 1: нет настройки «memy». Есть: memory, scale, nce…». Опечатка в имени
настройки — это ошибка загрузки, а не «плагин молча ничего не делает».

## Как выглядит и почему так

Экран тёмный, почти чёрный, с подсветкой сверху. Это не стиль ради стиля: игра в
эмуляторе — тёмный кадр, и светлая панель вокруг него мешает смотреть.

Цвет в приложении отвечает на вопрос «что это», а не украшает:

| Что | Цвет |
|---|---|
| **Игра** | Свой оттенок из её Title ID. Одна и та же игра всегда одного цвета, соседние — разных. Полоса слева и буква в кружке дают узнать игру раньше, чем вы прочитали название |
| **Формат файла** | `nsp` — голубой, `xci` — лаймовый, `nsz` — янтарный, `DLC` — фиолетовый |
| **Второе ядро** | Розовый. Везде: карточка Kenji-NX, точка у «своих» настроек, пометка `kenji` на плитке игры |
| **Eden** | Голубой |
| **Кнопки** | У каждой свой цвет, и тот же цвет у экрана, куда она ведёт: «Конвертер» янтарный, «Инструменты» розовые, «Руководство» синее |

Ничего не держится на одном цвете: рядом всегда есть слово. Цвет только ускоряет,
он не заменяет подпись — иначе тем, кто не различает оттенки, пришлось бы угадывать.

Текст поверх цветных плашек выбирается по яркости, а не «белый, потому что красиво»:
контраст проверяется тестом, минимум 4.2 к 1.

https://gofile.io/d/3cIAKSo5) — с новым оформлением и обоими ядрами. Три вещи, которые видно сразу:

## 9. Два ядра: гибрид

В приложении два ядра — **Eden** (встроен) и **Kenji-NX** (~55 МБ, скачивается один раз).
Где одно падает, другое иногда едет, поэтому ядро выбирается не на всё приложение, а на игру.

- **Выбрать ядро для игры.** Долгое нажатие на плитке в библиотеке → «Запустить на Eden» или
  «Запустить на Kenji-NX». Выбор запоминается за этой игрой, а пометка «kenji» на плитке
  показывает, каким ядром она пойдёт.
- **Скачать второе ядро.** «Инструменты» → «Два ядра» → «Скачать». Игры, сейвы и ключи общие:
  скачивается только ядро, библиотеку заново собирать не нужно.
- **Как связаны настройки.** Общие строки — масштаб, режим дока, кэш шейдеров, NCE — второе
  ядро берёт у Eden, пока вы не измените их на экране «Два ядра». Свои — память, PPTC,
  macro HLE, анизотропия, интернет, проверка целостности — принадлежат только ему, и Eden их
  не перетирает. Нажатие на строку переключает значение; «Вернуть значения Eden» снимает все
  ваши переопределения.
- **Ядро по умолчанию.** Тем же экраном: с ним запускаются игры, у которых своего ядра нет.
- **Если второе ядро не скачано.** Игра всё равно запустится — на Eden, и приложение скажет,
  почему не на том ядре.

Переключение ядер больше ничего не стирает: у Eden свой конфиг, у Kenji свой, а выбор ядра для
игры — одна короткая запись.

## 10. Если медленно

На Mali-G57 с 8 ГБ помогает не «включить всё», а изменить три вещи.

- **Масштаб 0.75x.** Настройки → Графика → Разрешение. Заметная часть работы GPU уходит
  на пиксели, которых на экране телефона не видно.
- **Подбор FPS.** «Инструменты» → «Подбор FPS»: ставит настройки под это устройство,
  а не «максимум качества».
- **Диагностика.** Показывает, какие настройки доехали до драйвера, а какие Mali молча
  выбросил. «Включено, но не работает» здесь — обычное дело.

## 11. Сейвы, папка данных, перенос

- **Где сейвы.** Папка данных (по умолчанию — внутренняя память приложения) → `saves`.
  Свойства игры показывают «сейв 128 КБ», если он уже есть.
- **Сменить папку данных.** «Инструменты» → «Утилиты» → сменить папку данных, затем
  перезапустить приложение. Папку с играми это не затрагивает.
- **Перенос на другой телефон.** Скопируйте папку данных целиком: там сейвы, шейдеры и
  настройки игр. Игры можно не копировать — достаточно заново указать папку.

---

## 8. Если что-то не так: порядок проверки

Проверяйте сверху вниз, пока не найдётся причина. Каждый пункт — один экран.

1. **Список пуст.** «Папки» → добавить папку. Если папка уже есть — потяните список вниз:
   это повторный обход.
2. **Игра не запускается.** Нажмите плитку: причина будет в диалоге. Чаще всего — нет
   ключей или образ сжатый.
3. **Чёрный экран или вылет.** «Инструменты» → «Диагностика» → отчёт о запуске: видно,
   что ядро приняло, а что выбросило.
4. **Одна игра идёт, другая нет.** Долгое нажатие на плитке → «Запустить на Kenji-NX».
   Игра, которая не идёт на одном ядре, иногда идёт на другом.
